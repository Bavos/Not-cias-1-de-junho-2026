# Downloads

Esta pasta organiza arquivos baixados pelo workflow N8N de download de render.

```text
downloads/
├── generated/
└── temp/
```

- `generated/`: armazena apenas arquivos finais baixados pelo workflow.
- `temp/`: deve ser usada apenas para arquivos temporários.

Arquivos de vídeo baixados ou gerados não devem ser commitados. Apenas os arquivos `.gitkeep` e este `README.md` devem permanecer no repositório.
